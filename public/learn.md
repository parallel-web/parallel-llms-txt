## Learn

This learning hub breaks down the key concepts behind web search for AI agents. It spans the stack from search-engine fundamentals like [web crawling](https://parallel.ai/learn/web-crawler), [web indexing](https://parallel.ai/learn/web-index), lexical and [semantic search](https://parallel.ai/learn/semantic-search), and [RAG](https://parallel.ai/learn/rag-retrieval-augmented-generation), up through agent mechanics like [context engineering](https://parallel.ai/learn/context-engineering), [tool calling](https://parallel.ai/learn/tool-calling), [grounding](https://parallel.ai/learn/grounding-llm), and [MCP](https://parallel.ai/learn/model-context-protocol).

Documentation for these layers is usually split between classic information-retrieval references and fast-moving agent guides. Every entry here is inter-linked so you can follow a thread across the whole stack, from an agent's tool call down to the retrieval and indexing layer answering it.

# Demos

Live apps built on Parallel APIs.

* ## [Said & Done](https://earnings-calls.paralleldemos.com/)  
Explore what public companies promised investors on earnings calls and in releases, and what happened, statement by statement.  
Products:  
Search API, Images API, Extract API, Task API, Monitor API  
Industry:  
Finance
* ## [Decisions API use cases](https://webjev-use-cases.paralleldemos.com/)  
Enter a company and get web-grounded ways it could use the Decisions API.  
Products:  
Search API, Images API, Decisions API  
Industry:  
Sales
* ## [Perpetual KYB](https://perpetualkyb.paralleldemos.com/)  
See company records rechecked field by field against the live web, with a source behind every flag.  
Products:  
Decisions API  
Industry:  
Finance
* ## [Archive Tracker](https://archivetracker.paralleldemos.com/)  
Get typed, cited answers about vintage resale listings, including the house, label, decade, and whether a piece walked a runway.  
Products:  
Decisions API  
Industry:  
Productivity
* ## [Every table in San Francisco](https://everytable.paralleldemos.com/)

Products:  
Decisions API  
Industry:  
Productivity
* ## [YC Listing Changes](https://ycstillactive.paralleldemos.com/)

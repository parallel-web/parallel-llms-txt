# Use Parallel with Zapier

Add Parallel web search and research to automated workflows across the apps you already use.

[Build a Zap](https://docs.parallel.ai/integrations/zapier)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Enrich leads, records, and content with current web data.
* Trigger Parallel research from thousands of connected applications.

## How it works

The official Parallel Web Systems app on Zapier exposes Task API actions: create an async web enrichment and fetch its result when it completes.

Zaps trigger Parallel research from thousands of connected apps and map the sourced output fields into downstream steps, with webhooks recommended over polling so workflows continue automatically.

## Set up in three steps

1. 1\. Choose the Parallel action in a Zap.
2. 2\. Connect the required Parallel credentials and map the input fields.
3. 3\. Test the output, map results into the next step, and publish the workflow.

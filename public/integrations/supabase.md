# Use Parallel with Supabase

Call Parallel from a Supabase Edge Function to add live web data to server-side application workflows.

[View Supabase setup](https://docs.parallel.ai/data-integrations/overview)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Add current web information to Supabase-backed applications.
* Keep Parallel credentials and calls in a server-side Edge Function.

## How it works

A Supabase Edge Function calls the Parallel API server-side, keeping credentials out of the client: the API key lives as a function secret and your app talks to a narrow endpoint.

Application workflows invoke the function to add live, sourced web data to Supabase-backed features.

## Set up in three steps

1. 1\. Review the data-integration overview and Edge Function pattern.
2. 2\. Store the required Parallel credential as a server-side secret.
3. 3\. Deploy the function, invoke a test request, and connect the output to the application.

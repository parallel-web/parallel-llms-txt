# Use Parallel with OpenCode

Add Parallel web search and research to OpenCode with the Parallel plugin.

[Install the OpenCode plugin](https://docs.parallel.ai/integrations/opencode-plugin)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Give OpenCode access to current web information during coding tasks.
* Use Parallel research without leaving the coding-agent workflow.

## How it works

The Parallel plugin gives OpenCode a suite of web tools it can call while it works: search, extraction, and research backed by Parallel's APIs.

Install the plugin, provide a Parallel API key, and the agent invokes Parallel automatically when a task needs live web information.

## Set up in three steps

1. 1\. Open the plugin setup guide and install the Parallel plugin.
2. 2\. Configure the required Parallel credentials.
3. 3\. Run a web-research prompt and verify the plugin returns sourced results.

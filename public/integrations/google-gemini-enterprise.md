# Use Parallel with Google Gemini Enterprise

Use Parallel as a grounding provider in Gemini Enterprise for current, source-backed web information.

[Configure Gemini grounding](https://docs.parallel.ai/integrations/google-gemini-enterprise)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Ground Gemini Enterprise experiences in current web information.
* Use Parallel retrieval as part of an enterprise model workflow.

## How it works

Parallel Search is an external grounding provider in the Gemini Enterprise Agent Platform (formerly Vertex AI).

Configure it through Google Cloud Marketplace for automatic authentication and consolidated billing, or bring your own Parallel API key per request; either way Gemini grounds responses with up-to-date, source-backed web context.

## Set up in three steps

1. 1\. Open the Gemini Enterprise integration guide.
2. 2\. Configure Parallel as the grounding provider and add the required credentials.
3. 3\. Run a grounded query and verify the response uses current source context.

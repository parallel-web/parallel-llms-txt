# Use Parallel with Google Antigravity

Search the web and read pages in Google Antigravity with the Parallel plugin or the Parallel Search MCP Store connector.

[Add Parallel Search to Antigravity](https://github.com/parallel-web/parallel-antigravity-plugin#install)

## What you can do

* Find the latest documentation for a library before updating your code.
* Give Antigravity a changelog URL and ask which changes affect your project.

## How it works

The plugin and the MCP Store listing connect to the same free Parallel Search MCP server. Install either one to use web\_search to find current sources and web\_fetch to read a page. You don't need a Parallel account or API key.

To add Parallel Search directly in the Antigravity App, open Customizations, then Installed. Under MCP Servers, click +, find Parallel Search and click Add.

In Antigravity IDE, open the menu at the top of the agent side panel and choose MCP Servers. Find Parallel Search in the MCP Store and click Install.

## Set up in three steps

1. 1\. In the Antigravity App, open Customizations and select Marketplace.
2. 2\. Find Parallel under Developer Tools and click + on its card to install the plugin.
3. 3\. In your project, ask Antigravity to find the latest release notes for a library you use and read the section on breaking changes. Look for web\_search and web\_fetch in the tool activity.

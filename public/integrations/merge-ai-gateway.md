# Use Parallel with Merge AI Gateway

Route web search through Parallel from Merge AI Gateway.

[Open the Merge guide](https://docs.merge.dev/merge-gateway/features/web-search)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Add web search behind a gateway-managed model workflow.
* Keep provider selection and application requests centralized in Merge AI Gateway.

## How it works

Merge AI Gateway exposes web search as a gateway feature with Parallel as a selectable provider.

Requests routed through the gateway can invoke Parallel search without per-application integration work, keeping provider selection and credentials centralized in one place.

## Set up in three steps

1. 1\. Open the Merge web-search documentation.
2. 2\. Select or configure Parallel as the web-search provider and add the required credentials.
3. 3\. Send a test gateway request and inspect the search result and source payload.

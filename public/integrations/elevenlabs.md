# Use Parallel with ElevenLabs

Give ElevenAgents live web search and research with Parallel as a custom integration.

[Open ElevenLabs guide](https://elevenlabs.io/docs/eleven-agents/customization/integrations/parallel)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Ground voice agents in current web information.
* Use Parallel results inside conversational agent workflows.

## How it works

Parallel is available as a custom integration for ElevenAgents, configured from the ElevenLabs dashboard.

Once connected, an agent can call Parallel mid-conversation to search the live web and ground its responses in current, source-backed information.

## Set up in three steps

1. 1\. Open the Parallel integration guide in the ElevenLabs documentation.
2. 2\. Configure the integration and required Parallel credentials.
3. 3\. Attach it to an ElevenAgent and test a web-research request.

# Use Parallel with Google Cloud Marketplace

Procure and manage Parallel through Google Cloud Marketplace using your existing cloud purchasing workflow.

[View Google Cloud setup](https://docs.parallel.ai/integrations/google-cloud-marketplace)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Purchase Parallel through an established Google Cloud procurement path.
* Centralize billing and vendor management with existing cloud spend.

## How it works

Parallel is listed on Google Cloud Marketplace, including a Zero Data Retention offering, so procurement runs through the purchasing workflow your organization already uses.

Subscribing consolidates billing through Google Cloud and enables automatic authentication for Gemini Enterprise grounding, with activation validated by a test request.

## Set up in three steps

1. 1\. Open the Google Cloud Marketplace setup guide.
2. 2\. Review the listing and complete the required procurement steps.
3. 3\. Follow the activation instructions and validate access with a test request.

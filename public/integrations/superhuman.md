# Use Parallel with Superhuman

Bring Parallel-powered web research into Superhuman through its Agent Store.

[View Superhuman setup](https://docs.parallel.ai/integrations/superhuman)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Research companies, people, and topics from an assistant workflow.
* Bring current web context into work already happening in Superhuman.

## How it works

Parallel is listed in the Superhuman Agent Store, so research runs where email work already happens.

After connecting the listing, Superhuman can call Parallel to research companies, people, and topics and return results with source context inside the assistant workflow.

## Set up in three steps

1. 1\. Open the Parallel listing or setup path from the linked guide.
2. 2\. Complete the required connection or authorization.
3. 3\. Run a research task and confirm the result includes useful source context.

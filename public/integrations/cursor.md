# Use Parallel with Cursor

Add Parallel to Cursor through the plugin marketplace, an Agent Skill, or one-click MCP setup.

[Set up Cursor](https://docs.parallel.ai/integrations/cursor-marketplace)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Let Cursor search and research the live web while coding.
* Choose a marketplace, skill, or MCP installation path.

## How it works

The Parallel plugin from the Cursor Plugin Marketplace adds web search, content extraction, deep research, and data enrichment as slash commands and automatic Agent Skills.

It runs on the Parallel CLI with your API key; teams that prefer MCP can use the one-click MCP install instead, and skills can also be installed manually.

## Set up in three steps

1. 1\. Choose Plugin Marketplace, Agent Skill, or MCP based on your preferred workflow.
2. 2\. Follow the guide to install and configure Parallel credentials.
3. 3\. Ask Cursor to perform a web-research task and confirm the Parallel tool is invoked.

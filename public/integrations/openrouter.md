# Use Parallel with OpenRouter

Select Parallel as the web search engine behind OpenRouter requests.

[Configure OpenRouter](https://docs.parallel.ai/integrations/openrouter)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Add Parallel web search to model requests routed through OpenRouter.
* Keep model routing and web-search configuration in one request path.

## How it works

OpenRouter's web\_search server tool lets any model on the platform decide when to search the web.

Set the engine to parallel and OpenRouter routes search requests through Parallel's Search API, returning results as annotations on the model response with no separate integration code.

## Set up in three steps

1. 1\. Open the OpenRouter integration guide.
2. 2\. Select Parallel as the web-search engine and configure the required credentials or request fields.
3. 3\. Send a test request and verify current, sourced web information is returned.

# Use Parallel with Vercel AI SDK

Add Parallel web search and research to AI SDK apps through the Parallel toolkit, AI Gateway, or Vercel Marketplace integration.

[View Vercel setup](https://docs.parallel.ai/integrations/vercel)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Add current web search to AI SDK applications.
* Choose the Vercel integration path that best matches your stack.

## How it works

Parallel Search ships as a built-in tool in Vercel AI Gateway: any model routed through the gateway can call it when a prompt needs current information, with no provider-specific code.

Teams that want a package instead can use the Parallel toolkit with the AI SDK directly, and the Vercel Marketplace integration handles account connection and billing through an existing Vercel workflow.

## Set up in three steps

1. 1\. Choose AI SDK toolkit, AI Gateway, or Marketplace as the integration path.
2. 2\. Follow the linked guide to configure Parallel and any required credentials.
3. 3\. Run a test request, inspect the returned sources, and add the flow to your application.

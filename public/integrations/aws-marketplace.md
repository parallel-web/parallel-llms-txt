# Use Parallel with AWS Marketplace

Procure and manage Parallel through AWS Marketplace using your existing cloud purchasing workflow.

[View AWS Marketplace setup](https://docs.parallel.ai/integrations/aws-marketplace)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Purchase Parallel through an established AWS procurement path.
* Centralize billing and vendor management with existing cloud spend.

## How it works

Parallel is listed on AWS Marketplace, so procurement runs through the purchasing workflow your organization already uses.

Subscribing consolidates Parallel usage into existing AWS billing and vendor management, and activation follows the listing's instructions with a standard Parallel API key at the end.

## Set up in three steps

1. 1\. Open the AWS Marketplace setup guide.
2. 2\. Review the listing and complete the required subscription or procurement steps.
3. 3\. Follow the activation instructions and validate access with a test request.

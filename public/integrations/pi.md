# Use Parallel with Pi

Extend Pi with Parallel-powered web search and research.

[Install the Pi extension](https://docs.parallel.ai/integrations/pi-extension)[Get an API key](https://platform.parallel.ai/)

## What you can do

* Give Pi current web context while it works on development tasks.
* Bring sourced Parallel research into the coding-agent loop.

## How it works

The Parallel extension registers web search and research tools with Pi, so the agent can pull current, sourced web context into its coding loop.

Install the extension, configure a Parallel API key, and Pi calls Parallel when a prompt needs live information.

## Set up in three steps

1. 1\. Open the extension setup guide and install the Parallel extension.
2. 2\. Configure the required Parallel credentials.
3. 3\. Run a web-research prompt and confirm the extension returns sourced results.

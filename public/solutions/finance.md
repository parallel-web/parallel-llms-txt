## FAQs

* **Can I use Parallel to automate KYB/KYC checks?**  
Yes. Parallel's KYB/KYC use case returns registry status, beneficial ownership, sanctions screening, and adverse media in one cited, confidence-scored profile — screened at onboarding and continuously afterward with the [Task](https://docs.parallel.ai/task-api/task-quickstart) and [Monitor](https://docs.parallel.ai/monitor-api/monitor-quickstart) APIs.
* **How does Parallel source financial data, and is it real-time?**  
Parallel pulls live filings, news, and market data from the open web at query time — not from a static dataset. Every answer includes citations and source excerpts so analysts can verify and defend each claim.
* **Is Parallel suitable for regulated financial workflows?**  
Yes. Parallel is SOC 2 Type 2 certified, with zero data retention available for enterprise customers, plus HIPAA-ready and GDPR options and SSO/SAML — the same enterprise trust posture used by teams building AI analysts for investment banks.

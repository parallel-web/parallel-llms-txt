## FAQs

* **How fast is a Parallel Search and Extract call for in-product use?**  
Pair [Search](https://docs.parallel.ai/search/search-quickstart) (turbo \~200ms; basic \~1s) and [Extract](https://docs.parallel.ai/extract/extract-quickstart) for current, grounded answers with clean source text — fast enough to run in the request path of your product.
* **Can I add a "deep research" feature to my app using Parallel?**  
Yes. Use the [Task API](https://docs.parallel.ai/task-api/task-quickstart) configured for deep research to ship structured, cited in-app reports — the same building blocks teams use for account briefs and thesis-level research, exposed as a product feature.
* **How does Parallel keep a knowledge base or feed current?**  
The [Monitor API](https://docs.parallel.ai/monitor-api/monitor-quickstart) tracks topics, sources, and entities continuously and sends alerts when something appears or changes — so feeds and knowledge bases stay fresh without manual refresh jobs.
* **Does Parallel work well for consumer AI assistants like companions?**  
Yes. Poke, the AI companion from Interaction, runs Parallel monitors on whatever each user cares about and starts the conversation when something happens — cited, proactive research that feels native in a consumer assistant.

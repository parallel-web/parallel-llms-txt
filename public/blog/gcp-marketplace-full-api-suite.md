## Everything you need to build agents with web data

- [Search](https://parallel.ai/products/search): Live web results returned as dense excerpts your model can read directly.
- [Extract](https://parallel.ai/products/extract): Clean, structured content from any URL.
- [Task](https://parallel.ai/products/task): Multi-step research with structured outputs and verifiable citations.
- [Responses](https://parallel.ai/blog/responses-api): OpenAI Responses-compatible chat API with web grounding.
- [FindAll](https://parallel.ai/products/findall): Complete lists of entities that match your criteria.
- [Monitor](https://parallel.ai/products/monitor): Structured event streams when tracked sources change.

Each API runs on its own, or several compose into one pipeline. An agent can discover target accounts with FindAll, enrich each record with Task, and keep the results current with Monitor.

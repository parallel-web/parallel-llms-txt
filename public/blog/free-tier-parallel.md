# $5 in free Parallel credits, every month

Starting this week, every eligible Parallel organization with a credit card receives $5 in free credits each month. Credits are applied automatically and can be used across Parallel’s APIs and platform.

**How it works**

If your organization already has a card added, there’s nothing you need to do. Each month, your organization receives a new credit. Any unused balance expires at the end of the month.

Use it to try Parallel, power OpenClaw or Hermes agents, run daily research, prototype a product, or build something of your own. If you use more than $5, additional usage is billed to your card at standard rates.

Each eligible organization can receive one $5 monthly credit. A payment card can be used to activate monthly credits for one organization only. Marketplace and postpaid organizations are not currently eligible.

## What $5 covers

Parallel prices each request upfront, so you know the cost before it runs. At current prices, $5 covers up to:

- 5,000 Search API requests
- 5,000 Extract API requests
- 1,000 Task API runs
- 1,666 Monitor API executions

Or any combination of the above.

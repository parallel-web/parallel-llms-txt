# Parallel Search is now available in AWS Marketplace

Enterprise organizations building on AWS can now add Parallel Search to their agents through Amazon Bedrock AgentCore and draw down their AWS spend commitment for the first time.

Today, the [Parallel Search API is available in AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-apfsi3l2dqslu?applicationId=AWSMPContessa&ref_=ucaf&sr=0-1) for teams who want high-quality, low-latency, low-cost web search for their production agents. You can call it as a tool from any Amazon Bedrock model or add it as an MCP server in Amazon Bedrock AgentCore.

Parallel Search runs on our own web index, designed for how agents use the web. Each search returns ranked, compressed excerpts sized for an agent’s context window, so agents reach accurate answers with fewer calls and fewer tokens. For teams building on Amazon Web Services (AWS), that keeps production agents fast and affordable, with search starting at $1 per 1,000 requests.

## Why buy Parallel Search in AWS Marketplace

**Use your committed AWS spend.** Our AWS Marketplace listing carries the Deployed on AWS badge, so Parallel Search purchases are eligible to count toward your AWS commitment.

**No new vendor setup.** Purchases run through your existing AWS account and land on your AWS invoice. There’s no new billing relationship to set up. Private offers cover negotiated pricing, terms, and payment schedules.

**Works with any model.** Agents call Parallel as a tool, so it works with any model on Amazon Bedrock or from another provider.

**Enterprise ready.** Parallel is SOC 2 Type 2 certified and offers zero data retention.

**Add it once in Amazon Bedrock AgentCore.** Amazon Bedrock AgentCore builders can add the Parallel Search MCP Server to their Amazon Bedrock AgentCore Gateway as an [MCP server target](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-target-MCPservers.html). The gateway discovers Parallel’s tools automatically, and every agent connected to that gateway can call them.

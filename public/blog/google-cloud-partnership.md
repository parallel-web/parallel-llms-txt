# Parallel and Google Cloud Announce Partnership for Agentic Web Search on Gemini Enterprise Agent Platform

## The foundation of production AI agents: grounding

Enterprises are moving agents from pilots to production, where they handle mission-critical work like market research, competitive monitoring, data enrichment, and real-time customer answers. These agents are only as good as the information available to them, and a model working from its training data alone falls out of date and hallucinates. Grounding agents in live, verifiable web data is what makes their output reliable and accurate in production.

Today, we’re announcing product integration with Google Cloud that brings Parallel's agentic web search to Gemini Enterprise Agent Platform. Parallel is now natively available across the platform: callable in the [Gemini Enterprise API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-parallel), selectable as a grounding source in [Studio](https://console.cloud.google.com/agent-platform/studio/multimodal), and available to subscribe through [Google Cloud Marketplace](https://console.cloud.google.com/marketplace/product/parallel-web-systems-public/parallel-web-systems) with usage metered on your existing Google Cloud invoice. Enterprises can build production-grade agents with web access out of the box, without stitching together search, models, and billing across separate vendors.

## What is Grounding with Parallel Web Search?

Grounding with Parallel Web Search on Gemini Enterprise Agent Platform is a separate offering that connects Gemini models to public web data provided by Parallel Web Systems' Search API. This service combines Parallel's AI-native web index with Gemini's ability to decompose complex user prompts, distill insights from the most relevant search results, and generate highly accurate answers complete with precise citation annotations. Because Parallel Web Search runs on Google Cloud, enterprises benefit from a streamlined, secure integration directly within their existing cloud environment.

## Expanded flexibility for enterprise and agentic workloads

Grounding with Parallel Web Search gives Gemini Enterprise Agent Platform customers expanded flexibility for enterprise and agentic use cases, including:

- **Output ownership:** Customers own all inputs and outputs, and may use, modify, and distribute outputs across your applications
- **Programmatic and agentic access:** Autonomous agents call search as part of multi-step workflows with no human in the loop.
- **Multi-model routing:** Send outputs to any downstream model or application, regardless of provider.
- **Storage and modification:** Cache, store, modify, and create derivative works from outputs for your business purposes.
- **Subsyndication:** Build grounded outputs into multi-tenant products you make available to your own customers.
- **No display requirements:** Full control over how results appear in your application, with no third-party branding obligations.

Together, these capabilities let enterprises run autonomous agents in production, enrich internal data with web sources, build on multi-model architectures, and distribute web grounding through their own products.

Enterprises can use Grounding with Parallel Web Search for use cases such as:

- Product catalog enrichment that fills data gaps across catalogs with millions of items, writing web-sourced attributes back into your own systems.
- CRM and account enrichment pipelines that keep contact and company records current from live web data.
- User-facing chat and answer experiences, from consumer apps to internal assistants, grounded in real-time web results.
- Competitor, market, and product intelligence stored, tracked, and compared over time.
- Autonomous monitoring and due diligence agents that scan dozens of web sources and route findings without human intervention.

## Get started today

Integrating Grounding with Parallel Web Search is simple and built directly into your Gemini Enterprise Agent Platform workflow. To get started, simply subscribe to the Parallel service via the [Google Cloud Marketplace](https://console.cloud.google.com/marketplace/product/parallel-web-systems-public/parallel-web-systems), accept the Terms of Service, and review the pricing. Purchases count towards your eligible marketplace benefits, with consolidated billing on your Google Cloud invoice.

After subscribing, navigate to [Agent Studio](http://console.cloud.google.com/agent-platform/studio/). From the navigation menu, click **+ New** and select **Chat**. Expand the **Model settings** pane and click the **Grounding with Partners** toggle to open the **Customize partner grounding** menu. Select **Parallel Web Search** as your grounding source, apply the configuration, and your Gemini model will be instantly ready to generate responses anchored in verifiable, real-time web information.
